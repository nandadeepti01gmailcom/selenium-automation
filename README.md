# Selenium Testing Project

## Overview
This project is a Maven-based Selenium testing framework designed for automated web application testing. It provides a structured approach to writing and executing tests using Selenium WebDriver.

## Project Structure
```
selenium-testing-project
├── src
│   ├── main
│   │   └── java
│   │       └── com
│   │           └── example
│   │               └── utils
│   │                   └── WebDriverUtils.java
│   └── test
│       └── java
│           └── com
│               └── example
│                   └── tests
│                       └── BaseTest.java
├── pom.xml
└── README.md
```

## Setup Instructions
1. **Clone the repository**:
   ```
   git clone <repository-url>
   cd selenium-testing-project
   ```

2. **Build the project**:
   Use Maven to build the project and download the necessary dependencies.
   ```
   mvn clean install
   ```

3. **Run the tests**:
   You can run the tests using Maven:
   ```
   mvn test
   ```

## Usage
- The `WebDriverUtils` class provides utility methods for initializing and managing the Selenium WebDriver instance.
- The `BaseTest` class serves as a foundation for your test classes, ensuring that the WebDriver is set up and torn down correctly.

## AI Prompt Template: Generate XPath You Can Paste in Browser
If you use an AI plugin (ChatGPT/Copilot/etc.), paste the prompt below and provide the target element HTML.

```text
You are an XPath generator for Chrome DevTools.
Given this element and nearby DOM context, return ONE robust XPath expression that I can directly paste in DevTools using:
$x("<xpath>")

Rules:
1) Prefer stable attributes in this order: id, name, data-testid, aria-label, title, role, visible text.
2) Avoid dynamic values (random ids, classes with hashes, autogenerated indexes).
3) Do not use absolute XPath from /html/body.
4) If text is used, normalize-space().
5) Output format must be exactly:
XPath: //...
DevTools: $x("//...")
Confidence: High/Medium/Low
Reason: <one line>

Element HTML:
<paste outerHTML here>

Optional parent/sibling HTML context:
<paste nearby HTML here>
```

### Quick validation in browser
1. Open DevTools (`F12`) → **Console**.
2. Paste the AI output from `DevTools: $x("//...")`.
3. Expect a non-empty array with exactly one intended element.
